
# IPL Auction SQL Analysis Project

## Project Overview
This project analyzes IPL Auction player data using SQL.

The project includes:
- Database creation
- Data import from CSV
- SQL analysis queries
- Aggregate functions
- Filtering and sorting
- Team-wise and player-wise analysis

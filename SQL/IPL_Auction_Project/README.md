# IPL Auction 2026 - SQL Analysis

## 📊 Project Overview

This project analyzes IPL auction data using SQL queries to extract meaningful insights about player pricing, team strategies, and auction trends.

## 🛠 Tools Used

* MySQL
* SQL (Aggregation, Group By, Filtering)

## 📈 Analysis Performed

* Total auction spending
* Most expensive players
* Team-wise spending
* Indian vs Overseas comparison
* Capped vs Uncapped analysis
* Price difference analysis

## 🧠 Key Insights

* Kolkata Knight Riders spent the highest amount
* Overseas players command higher average bids
* Uncapped players dominate in number
* Teams exceeded base prices due to competitive bidding

## 📌 Conclusion

SQL helps in extracting structured insights from raw data and supports decision-making in real-world scenarios.

# Main File
`loan_analysis.py`

## Libraries

### Pandas
Used for:
- CSV loading
- Data inspection
- GroupBy analysis
- Aggregation
- Filtering

### NumPy
Used for numerical operations.

### Matplotlib
Used for visualization.

## Main Analysis

The script demonstrates:
- Reading the cleaned CSV
- Checking dataset shape
- Checking columns
- Checking missing values
- Checking approval distribution
- Approval analysis by credit history
- Approval analysis by property area
- Approval analysis by education
- Creating a basic approval chart

## Run

Install dependencies:

```bash
pip install pandas numpy matplotlib
```

Then:

```bash
python loan_analysis.py
```

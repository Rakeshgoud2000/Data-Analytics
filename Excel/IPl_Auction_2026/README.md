
# 🏏 IPL Auction 2026 Data Analysis (Excel Project)

## 📊 Project Overview

This project analyzes the IPL 2026 auction dataset using Microsoft Excel. The objective is to understand player spending patterns, team strategies, and key auction insights through data analysis and visualization.

---

## 🛠 Tools & Techniques Used

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Data Visualization (Charts)
* Interactive Dashboard (Slicers)

---

## 📁 Dataset Details

The dataset includes:

* Player Name
* Nationality (Indian / Overseas)
* Base Price
* Winning Bid
* Team Name
* Player Type (Capped / Uncapped)

---

## 📊 Dashboard Features

* KPI Cards (Total Players, Total Spending, etc.)
* Team-wise spending analysis
* Top expensive players
* Indian vs Overseas comparison
* Capped vs Uncapped analysis
* Interactive filters using slicers

---

## 📈 Key Insights

1. The total auction spending is ₹2.15 Crores+, indicating strong investment by teams.
2. Cameron Green is the most expensive player, with a bid of ₹25.2 Crores.
3. Kolkata Knight Riders recorded the highest total spending among all teams.
4. Mumbai Indians recorded the lowest total spending in the auction.
5. Overseas players received higher total spending compared to Indian players.
6. Uncapped players dominate in number, whereas capped players attract higher average bids.
7. Top players contribute a significant share of the total auction spending.
8. Several teams significantly exceeded base prices, indicating highly competitive bidding.
9. Indian players (48) outnumber overseas players (29) in the auction.
10. Sunrisers Hyderabad have the highest number of uncapped players (8), highlighting their focus on emerging talent.
